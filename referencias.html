Justificación de Elementos Adicionales

Layout de 3 columnas: En pantallas de escritorio se usa CSS Grid con tres columnas: menú lateral izquierdo, contenido central y barra lateral derecha. Esto cumple con el requisito de estructura de 2 a 3 columnas.

Video embebido: Se incluye un video de YouTube en la página de inicio usando la etiqueta <iframe> para cumplir con el uso de recursos multimedia.

JavaScript: Se usa un archivo externo (js/main.js) para el menú responsive en celulares y para marcar la página activa en la navegación.

Imágenes: Las imágenes están en la carpeta img/ y fueron redimensionadas para que carguen más rápido en la web.

Variables CSS: Se usan variables en :root para los colores del equipo y mantener un diseño consistente en todas las páginas.

Organización del Proyecto

Los archivos del sitio están organizados en carpetas:

  • Raíz: archivos HTML (index, historia, jugadores, contacto, referencias)
  • css/: hoja de estilos styles.css
  • js/: archivo main.js
  • img/: imágenes del sitio (logo, calendarios, gráfico de jugadores)
